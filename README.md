# Axborot xavfsizligi — elektron darslik

KM.1 «Axborot xavfsizligi» moduli (30610403 Kompyuter tarmoqlari va IT-servis), 50 mavzu: 22 nazariy, 28 amaliy.

Fan maʼlumotlari: `lectures/fan.py` va `data/maruza.docx`. Ishchi dasturda faqat mavzular roʻyxati bor edi —
maʼruza matnlari, testlar va savollar `data/manba/` da yozilgan; docx shulardan yasaladi:

    python data/manba/yasash.py      # data/maruza.docx ni qayta yasash
    python manage.py import_docx     # bazaga yuklash
    python manage.py videolar        # YouTube video darslar
    python manage.py materiallar     # qonunlar va foydali havolalar
    python manage.py taqdimotlar     # PDF + PowerPoint taqdimotlar
    python manage.py sayt_yasash     # Netlify uchun sayt/ papkasi

Internetdagi sayt `sayt/` papkasidan (Netlify) joylanadi.
